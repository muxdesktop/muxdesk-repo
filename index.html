MuxOS — [muxdesk] pacman repo

The official package repo of the Arch-based MuxOS distribution. In pacman.conf:

[muxdesk]
SigLevel = Never
Server = https://muxdesktop.github.io/muxdesk-repo/$arch

Packages by architecture: x86_64 · aarch64 · arm · i686

LTS freeze: MuxOS 1.0 LTS (aarch64) pinned packages: lts/1.0/aarch64/ · LTS policy · pacman: [muxdesk-lts] Server = https://muxdesktop.github.io/muxdesk-repo/lts/1.0/$arch

Rootfs images and the app APK are published as assets in this repo's GitHub Releases.
