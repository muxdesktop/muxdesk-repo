MuxDesk — [muxdesk] pacman repo

The official package repo of the Arch-based MuxDesk distribution. In pacman.conf:

[muxdesk]
SigLevel = Never
Server = https://muxdesktop.github.io/muxdesk-repo/$arch

Packages by architecture: x86_64 · aarch64 · arm · i686

Rootfs images and the app APK are published as assets in this repo's GitHub Releases.
